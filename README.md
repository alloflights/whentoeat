# 🥢 EatTogether 双人协同约饭排期助手

专为两个人（情侣、好友、饭搭子）设计的实时协同约饭应用。两人可以共同打开网页，各自标记空闲时间，输入心愿餐厅及优先级，系统自动计算时间交集并按优先级步进式匹配排期：**排完第一个，手动选择后锁定并扣除该时间，紧接着自动排下一个！**

---

## ✨ 核心特性

1. **实时双人协同 (Real-time Multiplayer)**：
   - 两人通过同一个链接进入（如 `http://localhost:3001/?room=sweet-foodies`）。
   - 支持一键切换身份（“我”与“TA”），并可随时修改双方昵称。
   - 任何一方修改时间表或餐厅清单，对方屏幕毫秒级实时双向同步。

2. **空闲时间碰撞矩阵 (Availability Collision Matrix)**：
   - 支持未来 10 天各就餐时段（午餐 ☀️、下午茶 ☕、晚餐 🌙、夜宵 🍢）。
   - 粉色标明 User 1 有空，蓝色标明 User 2 有空。
   - **双方均有空的时段将自动闪烁高光标出（✨ 双方均有空）**，并支持一键快捷勾选周末晚餐。

3. **美食心愿单与优先级 (Restaurant Wishlist & Priority)**：
   - 记录店名、分类（火锅、烤肉、日料、西餐等）、优先级（🔥 P1 必吃、⭐ P2 很想吃、☕ P3 想尝试、📝 P4 备选）。
   - 支持就餐时段偏好与人均/订座备注。

4. **步进式自动排期引擎 (Step-by-step Auto Scheduler)**：
   - 按照优先级顺位，自动为第 1 顺位餐厅寻找双方重合且未占用的黄金时间。
   - 推荐首选时段，并列出所有可选重合时段；
   - **手动选择并确认后，该时段立即被锁定占用，餐厅进入已定行程，并无缝自动进入下一顺位餐厅排期**！
   - 全部排完后弹出庆祝动画与总结。

5. **敲定日程与微信分享 (Itinerary & WeChat Share)**：
   - 漂亮的时间轴时间线展示。
   - 一键复制格式化约饭清单文本，可直接粘贴发送到微信/备忘录。

## 🚀 启动与使用

### 1. 启动全栈服务
项目已配置就绪，直接运行以下命令即可：

```bash
# 启动生产服务（在 http://localhost:3001 查看完整应用）
npm start
```

若需进行本地代码开发调试（支持热重载）：
```bash
npm run dev
# Vite 前端开发服务: http://localhost:5173
# 后端 WebSocket 服务: http://localhost:3001
```

### 2. 双人协同操作体验
1. 打开浏览器访问 `http://localhost:3001`（可在同一台电脑打开两个不同标签页，或发送局域网 IP 给手机/另一台电脑）。
2. 一个窗口选择 **「我」**，另一个窗口选择 **「TA」**。
3. 在「空闲时段碰撞表」中，双方分别点击各自有空的时段，观察双方都有空的时段瞬间变成金色高光的“双方均有空”。
4. 在「美食心愿单」中添加 2~3 家想吃的店（设置不同优先级）。
5. 点击 **「✨ 智能排期」**，体验自动推荐、确认时间、扣除时段、自动弹入下一家店的流畅流程！
